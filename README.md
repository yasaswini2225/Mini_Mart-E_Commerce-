# MiniMart — Mini E-commerce Store

MiniMart is a responsive mini e-commerce website built using HTML, CSS, and JavaScript. It allows users to browse products, search and filter categories, manage their cart, register or log in, and try a demo checkout process.

## Features

* Display 20 sample products across five categories.
* Search products by name or keyword.
* Filter products by category.
* Sort products by price and rating.
* View product details, prices, discounts, and ratings.
* Register and log in to a demo account.
* Add and remove products from the cart.
* Increase or decrease product quantities.
* Calculate subtotal, delivery charges, and total price.
* Checkout using demo payment options.
* View order history.
* Responsive design for desktop and mobile screens.
* Light and dark theme support.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage
* Unsplash product images
* QRCode.js

## How to Run

1. Download or clone this repository.
2. Keep all three website files in the same folder.
3. Open `index.html` in a browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension.

## Important Notes

This is a front-end demonstration project.

* Account details, cart data, and orders are stored locally in the browser.
* No real payment is processed.
* The UPI QR code is for demonstration only.
* The website does not use a backend or database.
* Product images and some libraries require an internet connection.

Do not enter real payment-card details or sensitive personal information.
